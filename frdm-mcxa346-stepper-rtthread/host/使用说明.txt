RT-Thread 步进定位观测台

启动：双击上一级目录“打开上位机.cmd”。本机使用已有 Python + Tkinter + pyserial，无需改板上程序。默认连接 COM5、115200、8N1，连接只读取状态，不会启动运动。其他电脑需要 Python 3.9+（含 Tkinter）与 pyserial，可执行 python host/app.py。

操作：
1. 确认电机空载、接线不变，连接开发板。绿色“实时连接”表示正在接收有效数据。
2. “当前位置置零”设置软件参考点并清空此前测量，不能当作机械回零。若刚上电失能，第一次使能可能发生转子对齐；有精度比较需求时，先完成一次定位使能后再设置零点。
3. 输入角度后“转到该角度”，或者相对±10°、回零点。界面限制目标在软件零点±360°内。
4. “开始往返测试”：先到0°，再0°↔90°往返2至10次（默认3次），每段完成后停留1.5秒，全部结束自动停止并失能。
5. “演示”执行 goto10、goto90、move-45、goto0。相对-45°从当时反馈位置计算，终点不一定正好是绝对45°。
6. “停止并失能”或Esc中止动作；每段30秒超时。关闭/断开时尝试停止并失能。USB断线时停止命令可能无法送达，必要时用实体电源关闭驱动器。
7. “导出CSV”生成样本CSV、到位CSV和统计JSON，保存在工程 output/host-recordings。重新连接、置零、清空统计前先导出需要保留的数据。

数值解释：
- 角度 = 编码器计数 × 360 / CPR。CPR从板上config读取，本台标定值4096；1计数约0.087891°。这是计数量化间隔，不等于机械分辨率或绝对精度。
- 跟踪误差 = 目标计数－反馈计数，正值表示反馈小于目标。
- 绿色范围是固件±3计数到位容差，约±0.263672°。
- 本次运动采样RMS = sqrt(各串口采样误差平方的算术平均)，峰值也是这些采样的最大绝对值。它们包含运动过程，不是稳态精度指标；串口约3–4Hz，可能漏掉峰值，且并非严格等间隔采样。
- 到位误差：本上位机发出运动命令、收到对应命令回显和目标后，第一条reached=1/run=0/active=0/fault=none状态的误差。重复轮询已到位状态不会重复计次。
- 观测耗时：从上位机发起命令至收到到位状态，包含通信与采样延迟，不等于精确机械稳定时间。
- 重复离散程度：相同目标计数、相同指令位移方向、相同CPR，至少2次到位；显示反馈角度的极差与样本标准差(n-1)。方向按目标与开始计数比较，不代表测量了最后一个纠偏脉冲的方向。开始位移不超过3计数的操作不计入重复统计。
- 反馈闭环把读数控制在容差内，不代表轴在外部坐标系内同样准确；实际精度需要角度仪或标定装置。该程序不是按计量标准执行的精度认证。

连接与故障：
- 同一串口只能由一个程序占用，运行本上位机时不要同时运行串口助手或demo-stepper.py。
- 超过1.5秒没有新状态禁止继续动作并请求停止；3秒无有效状态断开。界面会把旧值标成“数据过期”。
- 本次连接仅保留最新12000条样本，显示最近30秒；到位统计保留本会话已完成命令。单条运动完成后保持使能，重复测试/演示结束后才自动失能。
- “清空统计”不改变电机位置；“当前位置置零”会改变软件参考点。

验证：
python -m unittest discover -s host -p "test_*.py" -v
协议解析、重复目标字段、命令与到位关联、方向分组、GUI记录与CSV导出有自动化验证。已通过COM5实物只读采集。运动逻辑使用已验证的板上goto/move命令；上位机新加入的多轮往返按钮须实际运行后才能报告其测量结果。
