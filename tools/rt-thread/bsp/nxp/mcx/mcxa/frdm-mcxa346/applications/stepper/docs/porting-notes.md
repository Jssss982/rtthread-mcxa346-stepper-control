# 移植说明

当前采用低速 GPIO 脉冲后端，见上级 README 的接线与验证步骤。旧 PWM 估算脉冲方案已替换。

- 不需要 PMSM FOC、三相逆变桥、Clarke/Park 或电流采样算法。
- `d36a_stepper_poll` 每次最多产生一个上升沿，相邻高低电平至少间隔一次控制调度；最后一个脉冲保留至下一周期才拉低。
- `stepper_axis_control_tick` 以实际输出脉冲数扣减有限运动，不以频率乘时间估算。
- 控制线程与 MSH 命令共用互斥锁；编码器 ISR 使用极短的临界区读取计数。
- 初始化、故障、使能/失能、模式切换和非法命令均有主机回归用例。
- 速度设定不等于高精度实测速度；串口输出或系统负载会使软件脉冲变慢。
- 若扩展到高速，应改用定时器硬件脉冲计数与硬件正交编码器，并补充加减速规划和真实负载测试。
